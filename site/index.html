Questions fréquentes

Avant de commencer.

La démo utilise-t-elle mes données ?+

Non. Le mode découverte de cette page utilise uniquement des valeurs fictives conservées en mémoire jusqu’au rechargement.

Atlas se connecte-t-il à ma banque ?+

Non. Les comptes et opérations sont saisis ou importés par l’utilisateur. Atlas ne demande aucun identifiant bancaire.

Où se trouve la base de données ?+

Sous Linux, elle est stockée par défaut dans ~/.local/share/atlas-portfolio/atlas.sqlite. Les emplacements Windows et macOS suivent les dossiers de données standards du système.

Pourquoi Windows ou macOS peuvent-ils afficher un avertissement ?+

Les installateurs ne sont pas encore signés officiellement. Windows ou macOS peuvent donc demander une confirmation lors du premier lancement.
